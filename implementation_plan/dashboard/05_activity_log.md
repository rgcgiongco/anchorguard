# Module 05 — Real-time Activity Log

## Goal
Implement the Real-time Activity Log table showing recent device events with timestamps and event types.

## Tasks
1. Create activity log table with columns: Time, Event, Device, Details
2. Event type badges: success (green), warning (orange), info (teal), error (red)
3. "Live" indicator with pulsing dot in table header
4. Sample events: device connected, app blocked, limit reached, device offline, policy updated
5. Table inside Card component with consistent styling
6. Responsive horizontal scroll on mobile

## Files
- `src/pages/Dashboard.tsx` — ActivityLog component

## Deliverable
Activity log table renders with event badges, timestamps, and live indicator.
