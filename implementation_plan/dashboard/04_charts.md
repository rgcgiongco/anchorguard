# Module 04 — Charts

## Goal
Implement Screen Time & Limits bar chart and App Usage donut chart using inline SVGs.

## Tasks
1. Screen Time & Limits chart:
   - Weekly bar graph (Mon-Sun) with minute values
   - Weekly/Daily toggle selector
   - Limit and average reference lines
   - Responsive height (320px)
2. App Usage donut chart:
   - SVG-based donut with 3 segments (Active Apps, Educational, Data Filter)
   - Center text showing total usage percentage
   - Legend with color swatches and percentages
3. Charts render inside Card components with consistent styling
4. No external chart library dependency (SVG-based)

## Files
- `src/pages/Dashboard.tsx` — ScreenTimeChart, AppUsageChart components

## Deliverable
Both charts render with correct data, colors, and responsive layout.
