# Module 6: Dashboard App — Empty States

## Goal
In-app empty states for when no devices or no activity data.

## Tasks
1. Create `src/pages/Dashboard.jsx` (app shell with sidebar)
2. No Devices state: Image `empty-devices.jpg` full page, heading "No devices connected", subhead, "+ Add Device" button (orange)
3. No Activity state: Image `empty-activity.jpg` full page, heading "No activity data yet", "View Setup Guide" + "Refresh Data" buttons
4. Sidebar navigation: Dashboard, Devices, App Blocker, Screen Time, Location, Reports, Settings
5. Responsive sidebar: collapsible on mobile

## Deliverable
Dashboard app with empty states
