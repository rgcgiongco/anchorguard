# Module 5: Authentication Pages

## Goal
Login and signup forms.

## Tasks
1. Create `src/pages/Login.jsx`
   - Logo at top, centered card, email/password fields, "Forgot password?", "Sign In" button (orange), "Create account" link → `/signup`
   - Trust badges below form
   - Background: subtle `hero-home.jpg` or `hero-alt.jpg` with dark overlay
2. Create `src/pages/Signup.jsx`
   - Logo at top, centered card, name/email/password/confirm fields, "Create Account" button, "Already have an account?" link → `/login`
   - Trust badges below form
3. Form validation: required fields, email format, password min 8 chars
4. Loading states on submit buttons

## Deliverable
Login at `/login`, Signup at `/signup`
