# Module 1: Design System & Shared Components

## Goal
Build reusable UI components and design tokens.

## Tasks
1. Create `src/components/ui/Button.jsx` — primary (orange), secondary (navy outline), ghost variants
2. Create `src/components/ui/Card.jsx` — white card with shadow, rounded corners
3. Create `src/components/ui/Input.jsx` — form input with focus states
4. Create `src/components/ui/NavLink.jsx` — navigation link with active state
5. Create `src/components/layout/Navbar.jsx` — logo, nav links, CTA button, mobile hamburger
6. Create `src/components/layout/Footer.jsx` — links, trust badges image, copyright
7. Define CSS variables for brand colors in `tailwind.config.js`
8. Create `src/lib/constants.js` — brand colors, API base URL, image paths

## Deliverable
Component library with consistent styling across all pages.
