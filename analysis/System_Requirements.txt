ARCHITECTURE OVERVIEW
================================================================================

Core Backend Components Required:
1. Auth & User Management          - Firebase Auth equivalent (email/phone/OIDC)

3. Push Notifications (FCM)        - FCM/APNs gateway + topic management
4. Remote Config / Feature Flags   - Firebase Remote Config equivalent
5. Analytics & Crash Reporting     - Firebase Analytics + Crashlytics equivalent
6. File/Asset Storage              - Firebase Storage / S3 equivalent (wallpapers, Lottie)
7. Custom API (REST + gRPC)        - Device config, licensing, reporting, key exchange
8. DNS Safe-Browsing Proxy         - DNS-over-HTTPS/TLS filter (kpsbproxy equivalent)
9. Licensing / Billing             - Play Billing + custom license validation
10. CDN                            - Static assets (images, animations, webp)

================================================================================
DNS SAFE BROWSING - BUILD VS BUY
================================================================================

Kids Place uses: Custom dnsjava VPN + kpsbproxy.kiddoware.com

Options for AnchorGuard:
1. Build custom (dnsjava/Go + blocklists):     ~$200-500/month at 10K devices
   - Full control, no per-query cost
   - Maintenance burden (blocklist updates, false positives)

2. NextDNS API (reseller):                     ~$0.50/device/month = $5,000/month at 10K
   - Zero maintenance, excellent categorization
   - Recurring cost scales linearly

3. CleanBrowsing / OpenDNS FamilyShield:       Free for basic, $2-5/device/year for API
   - Good middle ground

4. Hybrid: NextDNS for categorization, local DNS cache for performance
   - Recommended for 1K-10K scale

RECOMMENDATION: Start with NextDNS API (fast to market), migrate to custom at 5K+ devices.

DISASTER RECOVERY
================================================================================

RPO/RTO Targets by Tier:
- 100-1,000:  RPO 1 hour, RTO 4 hours (automated backup + manual restore)
- 3,000-5,000: RPO 15 min, RTO 1 hour (cross-region replica + automated failover)
- 10,000+:    RPO <1 min, RTO <15 min (multi-active + automated failover)

Backup Strategy:
- PostgreSQL: Point-in-time recovery (PITR) + daily logical dumps to S3/R2
- Redis: RDB snapshots every 60s + AOF
- Object Storage: Cross-region replication (CRR)
- Kubernetes: GitOps (ArgoCD/Flux) - cluster state in Git

================================================================================
SECURITY REQUIREMENTS
================================================================================

- All API traffic: mTLS (service mesh) or TLS 1.3
- Device communication: Certificate pinning + JWT (rotated weekly)
- Database: Encryption at rest (KMS) + in transit
- Secrets: Vault/Sealed Secrets (not in Git)
- Audit logging: All admin actions + config changes
- Penetration test: Annual (required for Play Store Data Safety)
- COPPA/GDPR/PDPA (PH) compliance: Data minimization, right to delete, age gating
